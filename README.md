# PES Team Roulette

Ứng dụng vòng quay chọn đội bóng phong cách PES/eFootball, hỗ trợ điện thoại và máy tính.

## Đưa lên GitHub Pages

1. Tạo repository mới trên GitHub, ví dụ `pes-team-roulette` (chọn **Public** để dùng GitHub Pages miễn phí theo cấu hình thông dụng).
2. Chọn **Add file → Upload files**, kéo thả **`index.html`** từ thư mục này vào gốc repository, chọn **Commit changes**.
3. Vào **Settings → Pages**, trong **Build and deployment**, chọn **Deploy from a branch**; chọn branch **main**, thư mục **/(root)** và **Save**.
4. Khi GitHub Pages báo đã phát hành, mở link: `https://TEN-TAI-KHOAN.github.io/pes-team-roulette/`.
5. Gửi đường link qua Zalo cho mọi người chơi.

Toàn bộ HTML/CSS/JavaScript nằm trong một file `index.html`, không cần cài thư viện.
